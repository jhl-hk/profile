# Arch Linux - Part 1

As a tech geek, its caught my attention for the choice of daily operating system. Experienced with MacOS and Windows, both system are fine and great in some aspects, but its not the ideal system that I am looking for. 

## Pain & Problems

Windows are doing great job in support game industry and a lot of specialized applications. MacOS build a nice eco-system with apple products, as well its base on Unix which it makes better compatility and easier to setup the develop environment compare to Windows. 

When working on more things at the same time or we say multitasking, it becomes hard to switch bewteen windows and looking for the right application. Estpecially everything became lagging when Firefox and Chrome ate up all the ram while running agents and compiling tasks. 

At the same time, working on MacOS for daily tasking, I often require misc application to support or achieve a specific function that which I think developer team should have considered it in the first place. When something went wrong, its harder for us to debug and fix which we need report and wait.

As the server maintenancer, I realized that I have an alternative choice that I skipped for a long time which is Linux. 

## Choose of distro and affect from my friends

People surrounding me have different opinions about all the distros in the community. Debian, Ubuntu, CentOS, NixOS and Arch are the names poping up surrounding me. I wish I can have something clean, easy to maintain, and mostly with the maximum extendability. 

All of my friends has their own needs and things that they are looking for. With my experience with Debian/Ubuntu and CentOS, I skipped CentOS and ubuntu on the first glance. I wish that I can try something refreshing and new that I have never used before. NixOS/Arch are the only two candidates left on the table for me to choose.

Before test arch linux, I have used nix for managing my MacOS applications and configuration which makes me think the idea of Nix is awesome that I can replicate my configurtaion on a device within minutes. Make the complex system into the form of declarable configuration files, but this route was not for me. Something its not worth to replicate and should have make it easier, and the most importance thing has not solve yet -- The window management.

Therefore I got help from one of my friend and setup the arch linux with the official documentation, which the system has attract me so much that I feel like I actually control the system instead of the vendors and makers of a laptop. From the core, the keyboard layouts, desktop environments, shells and so on.

## Arch Linux

As the first time, people always choose something that looks familiar and seems like easy to get started on. For me I chose to use plasma sets which it looks like the Windows system, compared to GNOME and others its the only one that seems friendly to me.
